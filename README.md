# Gulshan-e-Sehar Housing Society Website

This is the landing page and informational website for the Gulshan-e-Sehar Housing Society in Qasimabad, Hyderabad.

## Features
- **Responsive Design**: Built with Tailwind CSS.
- **Animations**: Uses Framer Motion for smooth scroll and entrance animations.
- **Modern UI**: Components based on Radix UI and shadcn/ui.
- **Dark Mode**: Integrated light/dark mode support.

## Tech Stack
- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)

## Setup & Development

To install dependencies and start the development server:

```bash
npm install
npm run dev
```

The site will be available on `http://localhost:3000` (or whichever port Vite allocates).

## Build

To build the project for production:

```bash
npm run build
```
